`content/using-claude.json` = "Claude, Actually: Get Real Work Done with AI", a standalone non-coder course teaching which Claude surface (Chat / Cowork / Code) to reach for. 7 modules across 2 blocks (b1 "Pick the right Claude": meet, decide; b2 "Use each surface well": chat, cowork, code, prompting, capstone).

**Why:** Audience is general knowledge workers with no technical background; tone is "smart friend who figured it out." It's re-skinned: SCENARIOS are the spine (authored 14, every one "real task → which surface + why"), CARDS are a reach-for-this cheat sheet (fronts = situations, backs = surface to use), and `PATTERNS` is `{}` so the code tab stays hidden.

**How to apply:** Evergreen constraints baked in and must be preserved on any edit: NO version numbers, NO Fable/Mythos, NO exact usage/rate-limit numbers, NO Max/Team dollar figures (describe as "higher tiers"). Only durable money framing allowed: Free $0, Pro $20/mo. Models taught as three durable tiers only: Haiku (fast/light), Sonnet (balanced default), Opus (most capable). Core decision framing (Anthropic's own): "Chat for a one-off question or thought partner; Cowork when there's a clear deliverable and the work touches your files or tools." Cowork = agentic mode in Claude desktop app (macOS/Windows) for non-coders, same engine as Code. Rule of thumb taught: "not living in a terminal? reach for Cowork." One shared usage limit across all surfaces.

Facts were supplied as ground truth by the requester (a separate accuracy reviewer re-checks). Thin spots flagged at authoring: exact plan feature boundaries (which connectors/Projects caps), and Claude-in-Chrome beta status — kept deliberately high-level to stay evergreen.
