The "Using Claude" course (content/using-claude.json) teaches general users to choose between Claude's surfaces: Chat, Cowork, Code. Reviewed 2026-06-18 — no factual/currency errors found; verified accurate against first-party sources.

**Verified facts (as of 2026-06-18, first-party):**
- **Cowork**: agentic mode in Claude Desktop, **macOS & Windows only**, not web/mobile (mobile only relays results to an active desktop). Available on **all paid plans (Pro, Max, Team, Enterprise)** — NOT "Pro-only." Course correctly says "Pro unlocks Cowork" without claiming Pro is the *only* tier, so it's fine. Source: support.claude.com/en/articles/13345190 + claude.com/product/cowork.
- **Same agentic engine**: Cowork and Claude Code share the same agentic engine/architecture + same Claude models; Cowork was built using Claude Code. First-party confirmed (anthropic.com/product/claude-cowork).
- **Plans**: Free $0 = Chat on web/iOS/Android/desktop, web search, memory across conversations, create files/execute code/artifacts, **max 5 Projects**, NO Code/Cowork. Pro **$20/mo** = adds Claude Code, Cowork, **Claude Design**, **unlimited Projects**, Research. Source: claude.com/pricing.
- **Free Projects cap = 5** (Pro = unlimited). Course's "a handful"/"only a few" framing is accurate.
- **One shared usage limit** across claude.ai/Code/Cowork/Design — confirmed (rolling 5-hr + weekly). Course correct.
- **Claude in Chrome**: browser extension (navigate/click/fill forms), **in beta**, **all paid plans (Pro/Max/Team/Enterprise)**, not Free. Course glossary/DEPTH correct. Source: support.claude.com/en/articles/12012173. NOTE: most time-sensitive claim — re-check beta status on future reviews (could go GA).
- **Claude Code surfaces**: terminal/CLI, VS Code + JetBrains IDEs, desktop app, web, Slack. Course's list matches. Source: code.claude.com/docs/en/platforms.
- **Model tiers** taught as 3 durable tiers only (Haiku fastest / Sonnet balanced default / Opus most capable). Deliberately no version numbers, no Fable/Mythos, no exact prices beyond Free $0 / Pro $20, no exact usage numbers — this is an intentional evergreen choice, NOT a defect.

**Could-not-verify (not an error):** The exact verbatim "Reach for Chat… one-off question or thought partner / Reach for Cowork… clear deliverable that touches your files or tools" wording is quoted by the course as "Anthropic's own words" but did not surface verbatim on current product pages (substance IS first-party confirmed). If this exact quote matters, locate the original Anthropic source; otherwise soften "in Anthropic's own words" to "Anthropic frames it as."

**Watchpoint:** Official pricing now lists a 4th Pro surface, **Claude Design**, alongside Cowork/Code. The course intentionally scopes to 3 surfaces and omits Design — deliberate, not an error.
